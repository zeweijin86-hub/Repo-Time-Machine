# v0.1.0 — The first archive

Repo Time Machine turns a repository's Git history into a **playable, explorable archive**.

![Repo Time Machine demo](https://raw.githubusercontent.com/zeweijin86-hub/Repo-Time-Machine/main/public/media/repo-time-machine-demo.gif)

## Included in this first release

- **Overview** — See commits, contributors, estimated code growth, languages, and the directory snapshot at a selected point in time.
- **Timeline** — Navigate meaningful project stages, tags, releases, refactors, and growth moments.
- **File Explorer** — Trace when a file appeared, who touched it, how often it changed, and how its estimated size evolved.
- **Commit Replay** — Stop on a commit to inspect the affected files, additions/deletions, and a controlled diff excerpt.
- **Local-first analysis** — Generate a portable `report.json` from a local Git repository using the bundled CLI; no account or private-code upload is required.
- **Public GitHub import** — Paste a public repository URL to explore recent public history directly in the browser.

## Try it

- Open the [live demo](https://repotime-ffym3eeu.manus.space).
- Run the local analyzer:

  ```bash
  pnpm install
  pnpm analyze /path/to/your/repository --output report.json
  ```

- Import `report.json` in the app.

## Known first-release limits

- The public GitHub route uses anonymous API access and focuses on recent commits.
- Local analysis currently reads up to 200 commits and uses Git's change statistics rather than language-specific ASTs.
- `report.json` can include paths, commit messages, authors, statistics, and controlled diff excerpts. Inspect it before sharing.
